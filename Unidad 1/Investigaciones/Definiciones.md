¿Qué es una API?
Una API es básicamente el intermediario que permite que dos aplicaciones independientes se comuniquen entre sí. Funciona como un contrato donde se definen las reglas, los mensajes y la forma en que un programa le pide información o ejecuta funciones en otro, permitiendo que compartan datos sin importar que estén programados en tecnologías totalmente distintas.

¿Qué es REST?
REST no es un programa ni una librería, sino un conjunto de guías y principios de arquitectura para diseñar servicios web. Su idea principal es organizar todo el sistema en torno a recursos específicos a los que se accede mediante URLs claras, aprovechando los verbos estandarizados del protocolo HTTP para realizar las acciones principales y asegurando que cada petición sea independiente al no guardar estado de sesiones anteriores.

¿A qué se refiere el término RESTful?
Decir que un servicio es RESTful significa simplemente que cumple de forma estricta con todas las reglas y buenas prácticas del estilo de arquitectura REST. Es el término que se utiliza para calificar a una API que respeta el uso adecuado de los métodos HTTP, la gestión de recursos limpios y la independencia de las peticiones.
